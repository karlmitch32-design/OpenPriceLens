# OpenPriceLens

A mobile-first UK shopping comparison starter focused on gaming PCs and computer components.

## Current starter status

- Supports product-name search and product-link search preparation.
- Photo selection can preview an image locally in the browser.
- Shopping links are external search links, not live verified offers.
- Live retailer pricing and automatic photo recognition are not connected yet.

## Publish with GitHub Pages

1. Open repository **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose branch `main` and folder `/(root)`, then save.
4. After the deployment completes, visit `https://karlmitch32-design.github.io/OpenPriceLens/`.

Never put private API keys in public frontend files. Real price search should use an authorised provider through a server-side endpoint.
