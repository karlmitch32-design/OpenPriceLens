Testing a VantaSpec price card

This separate page tests whether VantaSpec's official product-price widget displays correctly on our free GitHub Pages website, including on a phone.

Test only: this card is supplied by VantaSpec. It is not yet connected to OpenPriceLens search results, and this test does not mean the source has been fully adopted.

Example: XFX Radeon RX 9060 XT Mercury OC

The card below is embedded directly from the product's VantaSpec page. Prices and retailer availability are controlled by VantaSpec and may change.

The embed is expected to carry VantaSpec's attribution and send product-price clicks to the corresponding VantaSpec product page. Please check the card and click behaviour before deciding whether to use it more widely.

What we're checking

  • Does the price card load without an API key?
  • Does it fit the page on a mobile screen without horizontal scrolling?
  • Is VantaSpec attribution visible inside the card?
  • Do price links open the corresponding VantaSpec product page rather than sending visitors directly to a retailer?
  • Does the card remain usable if its content is a little taller than expected?

Nothing on this test page changes the main OpenPriceLens search page or its verified-offer catalogue.
